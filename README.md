## 📌 Project Overview

This project demonstrates how to manage and analyze big data using **Databricks, Apache Spark, Delta Lake, Python, and SQL**.

The project focuses on creating and managing Delta Tables, transforming data using Python, querying data with SQL, building visualizations and dashboards, and efficiently updating data using Delta Lake's **MERGE** operation and version control capabilities.

The project was completed as part of the Coursera Guided Project:

**Data Management with Databricks: Big Data with Delta Lakes**

---

## 🎯 Project Objectives

The main objectives of this project were to:

- Create Delta Tables in Databricks.
- Load JSON data into Databricks.
- Validate Delta Table schemas.
- Transform data using Python and Spark.
- Query Delta Tables using SQL.
- Create data visualizations and dashboards.
- Analyze monthly sales trends.
- Update Delta Tables using the `MERGE` operation.
- Explore previous versions of Delta Tables using time travel.
- Understand practical data management workflows using Databricks.
